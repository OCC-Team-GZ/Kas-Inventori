Pengaturan Google Apps Script

Masukkan URL Web App Google Apps Script Anda agar aplikasi dapat terhubung secara dua arah ke Google Spreadsheet.

Siap menguji koneksi...
Panduan Singkat Google Apps Script (GAS):

1. Buat Google Sheet baru, buka Extensions > Apps Script.

2. Salin kode template GAS di bawah ini, deploy sebagai Web App (Execute as: Me, Who has access: Anyone).

⚠️ Catatan Penting: Karena pembatasan keamanan browser (CORS), klik tombol di bawah untuk membuka Web App dan memberikan izin otorisasi Google jika pertama kali.
